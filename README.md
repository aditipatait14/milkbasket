# MilkBasket - Smart Dairy Management System

A full-stack web application for managing dairy products, orders, customers and inventory.

## Features✨
- Secure User Authentication & Authorization
- Role-Based Access Control (Admin & Customer)
- Product Catalog & Category Management
- Shopping Cart & Order Management
- Wishlist & Product Feedback System
- Online Payment & Cash on Delivery (COD)
- Admin Dashboard with Business Analytics
- Inventory & Stock Management
- Customer & Product Management
- Order Tracking & Order History
- Responsive User Interface

## Tech Stack
- Java 
- Spring Boot
- Spring Security
- Hibernate/JPA
- MySQL
- Thymeleaf
- Bootstrap
